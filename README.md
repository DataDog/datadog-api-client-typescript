# Node.js Datadog API Client V2

[![License](https://img.shields.io/badge/License-Apache%202.0-blue.svg)](https://opensource.org/licenses/Apache-2.0)

This repository contains the autogenerated V2 rewrite of the TypeScript client for the [Datadog API](https://docs.datadoghq.com/api/). The client code, feature files, and test data are generated from Datadog's public OpenAPI specifications by internal tooling. The client is split into packages by product area, under the `packages/` directory.

We welcome contributions that expand or improve the client's capabilities. As part of the pull request review process, Datadog's internal tooling may regenerate the affected code, feature files, and test data based on the proposed changes.

## Packages

- `packages/core` is `@datadog/datadog-api-client-core`: the configuration, authentication, HTTP and serialization runtime that every package depends on.
- `packages/<id>` is `@datadog/datadog-api-client-<id>`, for example `packages/monitors` is `@datadog/datadog-api-client-monitors`. A package exports one namespace per API version it covers, `v1` and `v2`.

See the `README.md` in each package directory for its APIs and installation.

## Migration

See [MIGRATION.md](./MIGRATION.md) to move from `@datadog/datadog-api-client`.

## Getting Started

Here's an example of listing downtimes:

```bash
yarn add @datadog/datadog-api-client-core @datadog/datadog-api-client-monitors
```

```typescript
import { createConfiguration } from "@datadog/datadog-api-client-core";
import { v2 } from "@datadog/datadog-api-client-monitors";

const configuration = createConfiguration();
const apiInstance = new v2.DowntimesApi(configuration);

apiInstance
  .listDowntimes()
  .then((data: v2.ListDowntimesResponse) => {
    console.log("API called successfully. Returned data: " + JSON.stringify(data));
  })
  .catch((error: any) => console.error(error));
```
